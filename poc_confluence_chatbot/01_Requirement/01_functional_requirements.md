# Confluence Chatbot - 기능 요구사항 (Functional Requirements)

## 1. 개요
본 문서는 Confluence Chatbot 프로젝트의 기능 요구사항을 정의합니다.

---

## 2. 시스템 컴포넌트별 기능 요구사항

### 2.1 Indexer (문서 색인 서비스)

| ID | 요구사항 | 설명 | 우선순위 |
|----|---------|------|----------|
| IDX-001 | Confluence 문서 조회 | Atlassian API를 통해 Confluence 문서를 조회할 수 있어야 한다 | 필수 |
| IDX-002 | 문서 변경 감지 | Confluence 문서의 변경(생성/수정/삭제)을 감지할 수 있어야 한다 | 필수 |
| IDX-003 | 문서 파싱 | Confluence 문서의 제목, 본문, 메타데이터를 파싱할 수 있어야 한다 | 필수 |
| IDX-004 | 임베딩 생성 | Agent를 통해 문서 내용의 벡터 임베딩을 생성할 수 있어야 한다 | 필수 |
| IDX-005 | 벡터 DB 저장 | 생성된 임베딩을 pg-vector에 저장할 수 있어야 한다 | 필수 |
| IDX-006 | 배치 스케줄링 | 정해진 주기로 문서 색인 작업을 자동 실행할 수 있어야 한다 | 필수 |
| IDX-007 | 증분 색인 | 변경된 문서만 선택적으로 색인할 수 있어야 한다 | 권장 |
| IDX-008 | 색인 상태 모니터링 | 색인 작업의 진행 상태와 결과를 조회할 수 있어야 한다 | 권장 |

---

### 2.2 Chatbot (대화 서비스)

| ID | 요구사항 | 설명 | 우선순위 |
|----|---------|------|----------|
| CHT-001 | 질문 수신 | 사용자로부터 자연어 질문을 비동기로 수신할 수 있어야 한다 | 필수 |
| CHT-002 | 문맥 검색 | 질문과 관련된 Confluence 문서를 벡터 검색으로 찾을 수 있어야 한다 | 필수 |
| CHT-003 | 답변 생성 | 검색된 문서를 기반으로 Agent를 통해 답변을 생성할 수 있어야 한다 | 필수 |
| CHT-004 | 출처 제공 | 답변과 함께 참조한 Confluence 문서의 링크를 제공해야 한다 | 필수 |
| CHT-005 | 대화 이력 관리 | 사용자별 대화 이력을 저장하고 조회할 수 있어야 한다 | 권장 |
| CHT-006 | 스트리밍 응답 | 긴 답변의 경우 스트리밍 방식으로 점진적 응답이 가능해야 한다 | 권장 |

---

### 2.3 Agent (LLM 에이전트)

| ID | 요구사항 | 설명 | 우선순위 |
|----|---------|------|----------|
| AGT-001 | 텍스트 임베딩 | sentence-transformers를 사용해 텍스트를 벡터로 변환할 수 있어야 한다 | 필수 |
| AGT-002 | 의미 검색 | pg-vector에서 유사도 기반 문서 검색을 수행할 수 있어야 한다 | 필수 |
| AGT-003 | 답변 생성 | Ollama LLM을 활용해 검색된 문맥 기반 답변을 생성할 수 있어야 한다 | 필수 |
| AGT-004 | 문서 분석 | Indexer 요청 시 문서 내용을 분석하고 구조화할 수 있어야 한다 | 필수 |
| AGT-005 | LangChain 통합 | LangChain 프레임워크를 통해 RAG 파이프라인을 구성할 수 있어야 한다 | 필수 |
| AGT-006 | 청킹 처리 | 긴 문서를 적절한 크기의 청크로 분할할 수 있어야 한다 | 권장 |

---

### 2.4 UI (사용자 인터페이스)

| ID | 요구사항 | 설명 | 우선순위 |
|----|---------|------|----------|
| UI-001 | 질문 입력 | 사용자가 텍스트로 질문을 입력할 수 있어야 한다 | 필수 |
| UI-002 | 답변 표시 | Chatbot의 답변을 화면에 표시할 수 있어야 한다 | 필수 |
| UI-003 | 대화 히스토리 | 이전 대화 내용을 스크롤하여 확인할 수 있어야 한다 | 필수 |
| UI-004 | 출처 링크 | 답변에 포함된 Confluence 문서 링크를 클릭하여 이동할 수 있어야 한다 | 필수 |
| UI-005 | macOS 지원 | macOS 데스크톱 앱으로 실행 가능해야 한다 | 필수 |
| UI-006 | Android 지원 | Android 모바일 앱으로 실행 가능해야 한다 | 필수 |
| UI-007 | 로딩 상태 표시 | 답변 생성 중 로딩 인디케이터를 표시해야 한다 | 권장 |
| UI-008 | 마크다운 렌더링 | 답변 내 마크다운 형식을 올바르게 렌더링해야 한다 | 권장 |

---

## 3. 통합 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|----|---------|------|----------|
| INT-001 | Indexer-Agent 연동 | Indexer는 Agent API를 호출하여 문서 분석/임베딩을 수행해야 한다 | 필수 |
| INT-002 | Chatbot-Agent 연동 | Chatbot은 Agent API를 호출하여 검색/답변 생성을 수행해야 한다 | 필수 |
| INT-003 | UI-Chatbot 연동 | UI는 Chatbot API를 통해 질문/답변을 주고받아야 한다 | 필수 |

---

## 4. 확정된 결정사항

> [!NOTE]
> 아래 항목들은 사용자 확인 완료된 사항입니다.

| 항목 | 결정 사항 | 비고 |
|-----|----------|------|
| **Confluence 인증 방식** | API Token (Basic Auth) | |
| **대상 Confluence Space** | 특정 Space만 색인 | Space Key 설정 필요 |
| **문서 권한 처리** | POC 범위 제외 | 향후 확장 기능으로 고려 |
| **동시 사용자 수** | 1~2명 | 로컬 LLM 사용, POC 목적 |
| **응답 시간 목표** | < 10초 | 로컬 LLM 성능 기준 |
