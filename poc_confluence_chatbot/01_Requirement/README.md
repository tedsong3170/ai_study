## 🎯 프로젝트 개요

**Confluence Chatbot**은 Confluence 문서에 대해 자연어로 질문하고 답변을 받을 수 있는 AI 기반 챗봇 시스템입니다.

### 핵심 컴포넌트

```
┌─────────────────────────────────────────────────────────┐
│                    사용자 (User)                         │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│                 UI (Flutter)                             │
│              macOS, Android 지원                         │
└─────────────────────┬───────────────────────────────────┘
                      │ REST API
                      ▼
┌─────────────────────────────────────────────────────────┐
│              Chatbot (Kotlin + Vert.x)                   │
│                   비동기 API 서버                         │
└─────────────────────┬───────────────────────────────────┘
                      │ HTTP API
                      ▼
┌─────────────────────────────────────────────────────────┐
│           Agent (Python + LangChain)                     │
│          RAG 파이프라인, 임베딩, LLM 연동                  │
└─────────────────────┬───────────────────────────────────┘
                      │
          ┌───────────┴───────────┐
          ▼                       ▼
┌─────────────────┐     ┌─────────────────┐
│   pg-vector     │     │     Ollama      │
│   (벡터 DB)      │     │   (로컬 LLM)    │
└─────────────────┘     └─────────────────┘
          ▲
          │
┌─────────────────────────────────────────────────────────┐
│             Indexer (Kotlin + Vert.x)                    │
│                    배치 색인 서비스                        │
└─────────────────────┬───────────────────────────────────┘
                      │ Atlassian API
                      ▼
┌─────────────────────────────────────────────────────────┐
│                 Confluence Cloud                         │
└─────────────────────────────────────────────────────────┘
```

## ✅ 확정된 결정사항

아래 항목들은 사용자 확인이 완료되었습니다:

| 항목 | 결정 사항 |
|-----|----------|
| Confluence 인증 | **API Token** |
| 색인 대상 | **특정 Space만** |
| Ollama 모델 | **gpt-oss 20b** |
| 문서 권한 | **POC 제외** (향후 확장) |
| 동시 사용자 | **1~2명** |
| 배포 환경 | **로컬 개발환경 only** |
